# Markdown | Shortcuts

Summary - Helpful shortcuts for markdown for both a Windows and Mac OS

<br>

| Action                       | Windows / Linux                                    | macOS                    | Notes                                                                                                 |
| ---------------------------- | -------------------------------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------- |
| **Bold Selection**           | `Ctrl` + `B` *(when supported by extension)*       | `Cmd` + `B`              | Wraps selected text with `**` in many Markdown extensions.                                            |
| **Format Markdown Table**    | `Alt` + `Shift` + `F`                              | `Option` + `Shift` + `F` | Formats the current Markdown table (requires a Markdown formatter or extension that supports tables). |
| **Format Document**          | `Shift` + `Alt` + `F`                              | `Shift` + `Option` + `F` | Formats the entire Markdown document using the active formatter.                                      |
| **Italic Selection**         | `Ctrl` + `I` *(when supported by extension)*       | `Cmd` + `I`              | Wraps selected text with `*` in many Markdown extensions.                                             |
