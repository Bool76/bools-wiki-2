Summary - This is at first going to be a high level description of the arch of the site and how it works

## Technology

Nuxt project - Used a starter template called Nitrogen that was inspired by Shopify  

Klaviyo - Tool marketing  and customer data platform. Site is integrated with it. Here are the ways Velocio is using it: 

- Back in stock notifications - The back in stock manages itself, when the product comes back in a notification gets triggered
- Custom email signup (in the footer) 
- Promotional pop up for 15% off  

Sanity - Site that's used to manage content. Site is integrated with it.   

Tailwind v4 - CSS styling framework
